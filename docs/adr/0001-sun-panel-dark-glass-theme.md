# 0001: 放弃明暗双主题，转向 Sun-Panel 深色玻璃单主题

日期：2026-09-02
状态：已接受

## 背景

项目原采用 heritage 暖色浅底 + 明暗双主题（`dark:` 变体覆盖全部组件，约 110 处），视觉基线自定义。用户希望整体对齐 Sun-Panel（NAS 导航面板）的 UI 设计。

## 决策

移除明暗切换，仅保留**深色玻璃单主题**：以用户壁纸为底、卡片半透明深色玻璃底（默认 `#2a2a2a6b`）、heritage 色板降级为强调色（Boston Clay 仅用于按钮/选中/focus）。卡片采用 Sun-Panel 双形态（详情卡/极简卡），每卡可选自定义背景色，文字按背景亮度自动黑白。

## 后果

- 正面：样式只写一遍；与 Sun-Panel 观感一致；壁纸玩法（遮罩/模糊/自定义背景图）成为一等公民。
- 负面：偏好浅色主题的用户失去选择；约 110 处 `dark:` 分支一次性删除（git 可回滚，但双主题回归成本高）。
- 数据模型新增卡片级 `backgroundColor`（可选，留空即默认玻璃底）；Sun-Panel 导入仍忽略该字段，避免与编辑器联动扩面。

## 备选方案

保留双主题、深色为默认：被否——玻璃风在浅色下观感打折，且每个组件都要维护两套类，维护成本翻倍。
