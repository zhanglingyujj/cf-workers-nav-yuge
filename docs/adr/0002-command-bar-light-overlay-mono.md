# 0002: 黑白灰配色、亮色浮层与命令面板浮岛取代通栏顶栏

日期：2026-09-03
状态：已接受

## 背景

ADR-0001 确立的深色玻璃单主题中，通栏固定顶栏承担 logo/标题、搜索栏、快捷分类标签三个职责，视觉拥挤；强调色沿用 Boston Clay（`#B8422E` 橙红）与深色玻璃底搭配显得刺眼、通用性差。快捷分类栏依赖 scrollspy 滚动高亮，但 header 占据固定高度、分类可见性与其占用的屏幕空间不成比例。

## 决策

1. **配色换黑白灰**：`heritage` 色阶整体替换为 zinc 灰阶（token 名不变）。交互强调一律用白/近黑，不再引入彩色强调色。
2. **明暗分层**：页面**内容区**（卡片、区块控件、浮岛）保持深色玻璃；所有**浮层**（下拉菜单、命令面板、弹窗、tooltip）统一亮色规格——白底 95% + 毛玻璃 + zinc-200 描边，文字 zinc 阶，悬停 zinc-200，选中态 zinc-800 深底白字，主按钮深底白字。
3. **通栏顶栏 → 命令面板浮岛**：顶栏三职责拆解——标题+搜索合并为与内容区边界对齐的居中玻璃浮岛（Command Bar × 浮岛），设置入口收进浮岛右端；快捷分类栏删除（scrollspy 一并移除），分类导航由命令面板承担（`Alt C` / `/` 唤起，键盘直达分类或站点，回车落到当前引擎）。
4. 站内搜索态以右上角"清除筛选"浮标提示，替代原搜索栏的清除按钮。

## 后果

- 正面：顶栏常驻高度从 ~110px 降至 56px；分类导航从"常驻占位"变为"按需唤起"，与 Homer/Dashy 等主流导航页范式一致；浮层亮色在深色页面上对比清晰，黑白灰对壁纸的适配性强于彩色强调。
- 负面：分类入口从"可见即点"变为"唤起后选"，多一次交互；快捷分类栏与 scrollspy 的直连心智（点标签跳分组）弱化为命令面板的模糊搜索直达。
- 兼容：`heritage` token 名未改，历史类名无需迁移；站点标题/壁纸设置共用 `/api/settings` 通道，无后端 schema 变更。

## 备选方案

- 精行页签（Vercel/Notion 式中轴分段页签）：保留分类常驻可见性，但顶栏仍占高度、与"壁纸为底"的玻璃气质冲突——被否。
- 全高侧栏（Arc/VSCode 式）：信息密度最高，但窄屏适配成本高、与单页滚动流不符——被否。
- 原型与选型过程见 `prototype/header-dock` 分支（v1 三变体 + v2 四范式，最终选 D Command Bar 并结合 G 浮岛）。
